# `AIRYIME1` 词典格式（权威）

本文件是引导期中文输入词典的字节级契约。实现见 `src/dict.rs`，任何改动
必须同时改这里与 `VERSION`；两者不一致即视为格式变更未评审。

## 1. 文件布局

```
+----------------------+  0
| 头（24 字节）         |
+----------------------+  24
| 词条表（12 × n）      |
+----------------------+
| 拼音池（pool_n 字节）  |
+----------------------+
| 文本池（其余全部）     |
+----------------------+
```

所有整数小端序。偏移量相对各自池的起点。

### 1.1 头

| 偏移 | 长度 | 字段 | 取值 |
|---|---|---|---|
| 0 | 8 | magic | `AIRYIME1`，逐字节比较 |
| 8 | 2 | version | 1 |
| 10 | 2 | flags | 0；保留，读取方不得解释非零值 |
| 12 | 4 | entries | 词条数 `n` |
| 16 | 4 | pool_n | 拼音池字节数 |
| 20 | 4 | crc32 | 覆盖头之后全部字节（词条表 + 拼音池 + 文本池） |

`crc32` 为 IEEE 802.3（反射多项式 `0xEDB88320`，初值与终值均取反）。

### 1.2 词条表项（12 字节）

| 偏移 | 长度 | 字段 | 说明 |
|---|---|---|---|
| 0 | 4 | text_off | 文本池内偏移 |
| 4 | 4 | py_off | 拼音池内偏移 |
| 8 | 1 | py_len | 拼音字节数，1..=255 |
| 9 | 1 | text_len | 文本字节数，1..=255 |
| 10 | 2 | freq | 词频，越大越靠前 |

表项顺序：先按拼音字节序非降序，同拼音按文本字节序升序。读取方校验
非降序；乱序整份拒绝，因为前缀检索依赖二分。

## 2. 编码约束

- 拼音：仅小写 ASCII `a-z`，无空格与分隔符；全拼，不做音节切分。
- 文本：合法 UTF-8，不含 NUL；单条不超过 255 字节。
- 文本池内的字符串不要求去重；同一文本可由多个拼音指向。
- 拼音池允许重复；同一拼音的多个词条共享同一段字节即可，也可各写一份
  （构建器对每个词条各写一份）。

## 3. 加载与校验

按顺序判定，任一失败即整份拒绝：

1. 长度不足 24 字节 → `Short`
2. magic 不符 → `Magic`
3. version 不为 1 → `Version`
4. 词条表或池偏移越界、字段为空 → `Bounds`
5. CRC32 不符 → `Checksum`
6. 拼音非小写 ASCII、文本非 UTF-8 或含 NUL → `Pinyin` / `Text`
7. 拼音顺序不成立 → `Order`

失败语义统一为 `ime=no-dict`：候选区显示不可用提示，键事件按 ASCII 直通，
不阻塞会话。**不做部分加载**。

## 4. 检索与排序

- 前缀检索：二分定位第一个拼音不小于前缀的词条，向后线性扫描到不再以
  该前缀开头为止。
- 空前缀、非 ASCII 前缀、`limit = 0` 一律返回空候选。
- 候选排序：词频降序 → 文本字节序升序 → 拼音字节序升序。
- 同文本多拼音：按上述顺序保留第一条，其余丢弃。
- 顺序不依赖时间、随机数或哈希遍历顺序；同一输入两次查询必须逐字节相同。

## 5. 进程协议（JSON Lines）

每条消息一行 JSON，字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `session` | string | 会话标识，非空 |
| `seq` | u64 | 同一会话内单调递增；重放定位键 |
| `msg` | string | `open` / `key` / `select` / `commit` / `reset` / `close` |
| `key` | string | 仅 `key` 消息出现 |
| `index` | u8 | 仅 `select` 消息出现 |

边界：

- 单条消息 ≤ 64 KiB（不含行尾换行）；超限判错并关闭会话，不截断。
- 附加字段与 `msg` 不一致（缺失或多余）判错。
- 键处理超过 50 ms 标记 `ime=slow`，结果不变；恢复超过 200 ms 建议改用
  ASCII。
- boot-tui 保留最近 256 条未提交键事件，进程崩溃重启后按 `seq` 重放。

### 5.1 会话推进

| 消息 | 状态变化 | 约束 |
|---|---|---|
| `open` | 不改组合状态 | 重复发送按空操作处理 |
| `key` | 追加一个小写 ASCII 字母并刷新候选 | 大写折小写；空串、多字符、非字母判错 |
| `select` | 选中第 `index` 条候选 | 越界判错，不夹取 |
| `commit` | 提交选中候选；无候选则提交原始全拼 | 组合与重放窗口同时清空 |
| `reset` | 清空组合 | 重放窗口同时清空 |
| `close` | 关闭会话 | 之后任何帧都拒绝 |

`seq <= 已处理序号` 的帧一律当作重放丢弃，不重复应用；这是崩溃恢复不会把
同一个字母打两遍的唯一依据。重放窗口只保留未提交动作，提交或重置即关闭。

## 6. 构建

`dict-build <words.tsv> <out.airyime>`：TSV 三列（全拼、文本、词频），
`#` 开头为注释。构建器对同拼音同文本的重复行保留最高词频，输出顺序固定，
同一输入两次构建逐字节相同。
